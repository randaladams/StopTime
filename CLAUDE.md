# StopTime – notes for working on this repo

Android game (Kotlin, single module `app`), package `com.adamselite.stoptime`. Published on Google Play by Randy Adams.

## Rules
- Never commit signing keys (`*.jks`, keystore base64, passwords). They live only in GitHub Secrets.
- Never put test AdMob IDs in release config or real IDs in debug; both are set at the top of `app/build.gradle.kts`.
- Don't edit `versionCode`/`versionName`; they come from the workflow (see README "Versions").
- Library/plugin versions go in `gradle/libs.versions.toml` only.
- Work on a branch and open a pull request; the "Android" workflow builds a test APK on every PR. Merge only when it's green.
- Releases: Actions → Android → Run workflow → version `x.y.z` (higher than the last `v*` tag).
- Keep user-facing text plain and friendly; the owner is new to Android development.

## Layout
- `MainActivity` game screen · `AchievementsActivity` list + reset · `achievements/` definitions + saving
- `ads/AdsManager` banner + interstitial · `Consent` (UMP) · `Premium` (Play Billing "remove_ads")
- `Sounds` (SoundPool, files in `res/raw`, generated by `tools/make_sounds.py`) · `FireworksView`
- `docs/` = GitHub Pages (privacy policy) · `store/` = Play listing assets
